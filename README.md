# Handan W (智能单据处理与 Excel 追加引擎)

> [!CAUTION]
> **特别声明 / Disclaimer**  
> 本项目**不是一个通用项目**，为针对作者个人特定业务流程、特有单据模板（销售单/采购单等）及数据汇总习惯深度定制的内部工具。所有解析规则、数据结构映射和 Excel 格式约定均有极强的个人场景专属性，不提供通用场景开箱即用支持。

---

## 1. 项目简介

本项目主要用于个人日常业务中的单据自动化处理与汇总，核心功能包括：

- **单据数据提取**：解析特定格式的 PDF 及各类业务单据明细数据。
- **Excel 高保真安全追加**：将结构化数据依据规则追加至目标工作簿（`result.xlsx`）对应 Sheet，自动保持行样式、公式动态联动以及防损坏事务覆盖。
- **轻量前端与监控**：提供简易 Web 操作面板与长任务执行日志实时回显。

---

## 2. 简要使用指引

### 环境要求
- Java 17+
- Maven 3.8+
- Node.js 18+ (如需运行前端 Web 界面)

### 配置文件
- `mapping-config.yaml`：定制字段映射及提取规则。
- `src/main/resources/application.yml`：配置数据工作目录与基础参数。

### 启动服务
1. **启动后端服务**：
   ```bash
   # 根目录下执行
   mvn spring-boot:run
   # 或在 IDE 中直接运行 Application.java
   ```
   服务默认监听端口：`http://localhost:8080`

2. **启动前端界面（可选）**：
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   本地访问开发服务器提供的地址即可进行页面交互与执行监控。
